# 表示確認メモ

- 初期表示では、見出し、入力欄、文字数、整理ボタン、結果領域、コピー操作、使い方パネルがポップアップ幅内に収まっていることを確認した。
- 「仕事ほどき」の名称と「誰が・いつまでに・何をするか」という主目的が、初見でも把握できる配置になっている。
- 実行ロジックは `parser-smoke.test.js` で別途検証する。ローカルHTMLとして開いた確認画面はChrome拡張機能の実行コンテキストではないため、保存・タブ取得処理は実拡張機能読み込み時に検証する。

実例「田中さん、来週火曜までに見積書のたたき台を作成してください。鈴木さんは金曜までに数字を確認願います。私は月曜に顧客へ連絡します。」で画面操作を確認した。結果は3件として表示され、各カードに「見積書のたたき台を作成／田中さん／来週火曜」「数字を確認／鈴木さん／金曜まで」「顧客へ連絡／自分／月曜」がそれぞれ表示された。コピー操作も有効化され、結果エリアに収まることを確認した。
