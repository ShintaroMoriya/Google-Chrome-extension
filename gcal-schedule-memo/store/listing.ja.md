# Chrome ウェブストア掲載文 — 日本語

## 名前（45文字以内）

日程アシスト

## 概要（132文字以内）

Googleカレンダーで候補日時を選び、相手のタイムゾーン・言語に合わせてコピー。日程調整を数クリックに。

## 説明

日程調整の「空き時間を探す → 日時を打つ → 時差を計算する → 文面を作る」を、カレンダー上のクリックと1回のコピーに置き換えます。

主な機能
• カレンダーから選ぶ: カーソルを合わせると、追加される時間帯が枠で表示されます。クリックすると追加されます。空き時間でも既存の予定でも選べます。
• 相手の時刻・表記でコピー: 相手の都市と表記（日本語 / English 12h / English 24h）を選ぶと、相手の時刻・言語・書式で候補が並びます。
• 相手の1日がひと目で分かる: ☀ 業務時間、🌅 早朝・夜、🌙 深夜。相手にとって日付がずれる場合は +1 / −1 も表示します。
• ワンタップでコピー: 候補のみ / 候補日を送る / 再調整のお願い / オンライン打合せの提案。
• スピード: Alt+Shift+S でパネルを開閉し、Alt+Shift+C でコピーします。最近の相手はワンタップで呼び出せます。
• 安心: カレンダーのクリックを使うのは、取得モードの間だけです。Esc でいつでも戻れます。ダークモードにも対応しています。

プライバシー
データはすべてブラウザ内に保存します。予定や候補を外部へ送信しません。アカウント登録・解析ツール・リモートコードもありません。権限は保存用（storage）と calendar.google.com へのアクセスだけです。

本拡張機能は Google とは関係ありません。Google カレンダーは Google LLC の商標です。
